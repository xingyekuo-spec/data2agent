## 1. 文档用途

本文件把 v0.2 路线图转换为可逐项执行、可暂停、可验收的任务队列。它只管理里程碑顺序、依赖、交付物、状态和证据，不重复详细实现步骤。

每个里程碑开始前建立独立任务文档；执行中只允许一个里程碑处于 `进行中`。当前只展开 M1，后续任务在前置契约稳定后按当时代码事实编写，避免提前固化错误假设。

## 2. 执行规则

1. 严格按 `M1 → M2 → M3 → M4 → M5 → M6` 推进；未通过退出门禁，不切换下一里程碑。
2. 每项任务按“契约或设计 → 实现 → 自动测试 → 页面验收 → 证据归档”闭环。
3. 现有 Jinja2 管理页、`/v0` 和管理 API 在迁移期间保持可用；不以 Vue 开发为由破坏应急入口。
4. Mock、Demo、Real 共用领域类型和组件；任何非真实数据必须持续展示环境标识。
5. `unknown`、请求失败和未执行不得转换为绿色、零数据或正常空列表。
6. 涉及在线映射编辑、生产 binding 发布、ERP 写回、多租户和 PostgreSQL 全量迁移的需求不进入 v0.2。
7. 映射编辑、E6b 增强和 PostgreSQL 改造不得与本队列并行抢占 1–2 人的关键路径。

## 3. 状态定义

| 状态 | 含义 |
| --- | --- |
| `待开始` | 前置条件尚未满足或尚未进入实施 |
| `进行中` | 当前唯一的主开发里程碑 |
| `待验收` | 实现完成，正在收集或复核门禁证据 |
| `已完成` | 退出门禁全部通过并记录证据 |
| `阻塞` | 存在无法由当前任务内部解决的外部依赖 |

“代码已合并”不等于“已完成”；没有自动测试、页面验收或约定的运行证据时，状态最多为 `待验收`。

## 5. 固定的产品与路由边界

### 5.1 页面边界

v0.2 发布必须具备以下 8 个主页面：

1. 总览；
2. 管道；
3. 运行；
4. 审计；
5. 数据；
6. 隔离；
7. 模板；
8. MCP Lab。

Settings 是只读辅助页，读取 `GET /api/config`，不计入 8 个主页面，也不承诺在线编辑生产配置。

### 5.2 挂载与兼容边界

- Vue Console 固定挂载于 `/v1`。
- `/` Jinja2 管理页和 `/v0` 简版页继续保留。
- 便携包缺少 Vue `dist` 时，`/v1` 必须明确提示“控制台未安装或未构建”，不得静默回落到其他页面。
- `/ingest/reconcile` 属于数据推送协议面；`/api/**` 属于控制台管理面，二者不因前端建设而合并。
- Token 只允许由前端保存在当前标签页的 `sessionStorage`，不得落入 `localStorage`、URL、日志或错误上报正文。

## 6. 跨里程碑完成定义

每个里程碑关闭前必须同时满足：

- 实现与当前任务文档的范围一致，没有顺带开放非目标写操作；
- 自动测试覆盖正常、空数据、失败、无权限以及适用的边界条件；
- 接口、生成类型和 fixture 没有未解释的漂移；
- 页面能区分 `MOCK / DEMO / REAL`，并正确表达 `unknown`；
- 相关文档和验收命令已更新；
- 没有新增明文 Token、敏感业务字段或无限制数据返回；
- `git diff --check` 通过，现有后端测试未回归。

## 7. v0.2 发布总门禁

M6 完成后按以下清单统一验收；任一必选项失败，版本不得标记为 v0.2 完成。

| 类别 | 必选验收 |
| --- | --- |
| 页面 | 8 个主页面可访问；Settings 只读可用；正常、空、运行、警告、失败和不可达状态均可呈现 |
| 真实性 | 页面持续展示 `MOCK / DEMO / REAL`；未知状态不变绿；错误不伪装为空数据 |
| 契约 | 后端 OpenAPI、仓库快照和 TypeScript 类型一致；漂移 CI 有失败用例 |
| 可观察性 | 不查看 SQLite 或自由文本日志即可判断链路状态并定位节点失败 |
| 安全 | 浏览接口有分页和上限；敏感字段有标识或脱敏；Token 不持久化到跨会话存储 |
| 兼容 | `/`、`/v0` 和既有管理能力仍可用；动作语义未被 GET 或页面加载隐式触发 |
| 分发 | 开发构建和便携包均验证 `/v1`；缺少 `dist` 时给出明确诊断 |
