# data2agent v0.2.0 Release Notes

> Date: 2026-07-21
> Target tag: `v0.2.0`
> Release branch: `codex/v0.2-m6-mcp-lab`

## Highlights

- Delivered the Vue Console at `/v1` with eight main pages: Overview, Pipeline, Runs, Audit, Data, Quarantine, Templates, and MCP Lab.
- Kept `/`, `/v0`, and existing management APIs compatible during the console migration.
- Added real read-only observability for pipeline health, run steps, access audit, raw/object browsing, quarantine state, and template governance.
- Added the MCP Lab for read-only object and metric queries plus "say-tier" proposal cards with process-scoped evidence.
- Closed the `/v1` distribution path for source runs, Docker builds, and Windows portable packages.

## Safety And Governance

- Unknown, failed, and unavailable states stay explicit; they are not rendered as healthy or empty success.
- Raw data and quarantine detail browsing use server-side pagination, masking, truncation, and access audit boundaries.
- Tokens remain session scoped in the Vue Console and are not persisted to local storage.
- Template, binding, metric, and proposal governance states remain visible and read-only.
