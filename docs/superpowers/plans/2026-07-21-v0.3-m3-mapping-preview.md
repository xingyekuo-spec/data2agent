## 1. 目标

在正式 apply 之前提供一个可重复、可比较、无业务副作用的映射试验台。用户选择对象、source 和有界 raw 样本后，可以用当前 binding 或一次性临时草稿执行与正式 apply 相同的字段解析、map、类型转换、derived 和业务键判断，并看到：

- 映射成功与将进入隔离区的行；
- 结构化失败原因，而不是依赖解析自由文本；
- 未覆盖枚举值及出现次数；
- 样本内业务键缺失和重复；
- derived 规则命中、默认命中、未命中与规则覆盖率；
- 当前 binding 与临时草稿在同一 raw 样本上的状态和字段 diff；
- `template_version`、当前/草稿 `binding_hash`、raw 批次和样本指纹。

M3 只提供试算和证据，不保存草稿，不修改模板，不创建候选对象表，不发布数据集，也不产生正式隔离记录。

## 3. 冻结契约

### 3.1 单一转换核心

正式 apply 和 Preview 必须调用同一个纯转换核心，转换顺序固定为：

```text
field expression 取值
  → map 翻译
  → enum 校验
  → 类型转换
  → derived 有序首命中/default
  → 业务键缺失/样本内重复判断
```

实施时将纯逻辑提取到 `data2agent/connect/mapping_transform.py`。核心返回结构化行评估；`mapping_apply.py` 只负责把评估结果适配为现有隔离文本、熔断和候选表写入。保留现有 `transform_object_rows()` 兼容包装，避免调用方和测试被一次性改写。

以下行为必须与正式 apply 保持完全一致：

- map 未声明源码值、对象枚举不匹配和类型转换失败的优先级；
- derived 规则按声明顺序首个匹配生效，之后才使用 default；
- 任一业务键为 `null` 即缺失；重复只在本次输入行集合内判断；
- 熔断条件继续使用正式实现的严格 `quarantined / total > threshold`，Preview 只报告 `would_trip_breaker`，不抛熔断和不写数据。

### 3.2 API

唯一公开端点：

```text
POST /api/mappings/{object}/preview
```

请求模型：

```text
MappingPreviewRequest
  source: string
  sample:
    limit: int = 50        # 1..200
    offset: int = 0        # 0..10000
    batch_id: string|null  # 可选；按锚表 _d2a_batch_id 精确筛选
  draft_binding: null | {
    tables: string[]
    key_map: object
    field_map: object
    derived: object
    watermark: string|null
    notes: string
  }
```

约束：

- `object` 必须来自当前 `TemplatePack`；`source` 必须来自当前配置或模板已声明来源；
- 未传 `draft_binding` 时使用当前启用 binding；对象/source 无当前 binding 返回 `409 current_binding_unavailable`；
- 传草稿时服务端构造 `status=draft` 的一次性 `SourceBinding`，不接受客户端伪造 verified/disabled；
- 草稿表达式必须通过现有 `SourceBinding`、`parse_field_expr()` 和 derived 模型校验；
- 草稿只能引用该 source 已由模板白名单声明且真实落地的 raw 表；不能通过草稿扩大 raw 访问范围；
- 存在当前 binding 时，草稿必须保持同一锚表 `tables[0]`，确保 before/after 使用同一 raw 行；允许在白名单内调整 join 表、field/key map 和 derived；
- 无当前 binding 时必须提供草稿，只返回 candidate 结果，diff 明确为 unavailable；
- 请求体、表数量、字段数量、derived 规则数和字符串长度设置显式上限，拒绝用超大草稿制造 CPU/响应放大。

### 3.3 样本选择与可重复性

Preview 在一个 SQLite 只读事务内完成样本冻结和 current/candidate 双跑：

1. 用 raw 锚表 DDL 主键按列序稳定排序；raw 表无主键时 fail-closed；
2. 过滤 `_d2a_deleted_at IS NULL`，可选精确过滤 `_d2a_batch_id`；
3. 应用有界 `offset/limit` 后冻结锚表主键元组；
4. current 和 candidate 的 `build_select()` 都用参数化主键条件读取同一组锚行；
5. 对 `source + anchor + 主键元组 + _d2a_row_hash + batch_id` 做规范化 SHA-256，返回 `sample_fingerprint`；
6. 返回排序后的 `sample_batch_ids`；指定批次不存在返回 `404 sample_batch_not_found`，合法空表返回成功空结果。

不得以客户端 SQL、任意列名、任意 `ORDER BY` 或未校验标识符选择样本。主键值不作为公开行 ID；响应中的 `sample_row_id` 使用样本内 ordinal 加摘要，不泄露敏感业务键。

### 3.4 响应

响应顶层至少包含：

```text
object / source / mode(current|draft)
template_version
current_binding_hash|null
candidate_binding_hash
sample {anchor_table, offset, limit, requested_batch_id,
        sample_batch_ids, sampled_rows, sample_fingerprint}
current|null
candidate
diff
warnings[]
```

每个评估结果包含：

```text
summary {total, mapped, quarantined, quarantine_rate, would_trip_breaker}
rows[] {sample_row_id, status, output, issues[]}
enum_gaps[] {field, source_value, count}
business_key_issues {missing, duplicate, scope="sample"}
derived_coverage[] {
  field, eligible_rows, matched_rows, default_hits, unmatched_rows,
  row_coverage, rules_total, rules_hit,
  rules[] {index, hit_count}
}
```

所有计数和覆盖率均以本次样本为口径。`eligible_rows` 是到达该 derived 字段求值阶段的行；`matched_rows + default_hits + unmatched_rows = eligible_rows`。`row_coverage` 在分母为零时返回 `null`，不伪装为 0% 或 100%。

### 3.5 结构化问题码

行级 `issues[].reason_code` 固定为：

```text
enum_unmapped
enum_invalid
type_coercion
derived_unmatched
derived_invalid_enum
business_key_missing
business_key_duplicate
```

每项同时返回 `field|null`、安全摘要 `detail` 和可选 `source_value`。`detail` 不包含 SQL、物理表名、traceback 或未脱敏原值。内部异常不降级为部分成功，统一返回安全 `500 + error_id`。

### 3.6 Diff 语义

“before”固定表示**当前模板 binding 在同一 raw 样本上的试算结果**，不是已发布对象表；已发布对象可能来自不同 raw 时点，M3 不做含混比较。

```text
diff.state = available | unavailable
diff.reason = null | no_current_binding
diff.summary {rows_changed, status_changed, fields_changed}
diff.rows[] {
  sample_row_id,
  status_before, status_after,
  fields[] {field, before, after}
}
```

只报告模板属性和状态变化；元数据列、内部派生辅助列和未声明 raw 列不得出现在 diff。JSON 比较使用规范化类型后的值，不能用展示字符串比较。

### 3.7 脱敏与审计

- Preview 与 raw 浏览采用相同的强制 Bearer 纪律：未配置 Token 返回 `403`，错误 Token 返回 `401`；不能因全局控制台未设 Token 而匿名开放；
- OpenAPI 显式声明 `HTTPBearer`；
- 输出属性按 `Property.sensitive` 永久服务端遮罩；问题中的源码值按目标属性敏感标记遮罩；未分类 raw 列不返回；
- current/draft 共同引用敏感属性时取敏感列并集，不能用草稿解除遮罩；
- 使用现有 `d2a_console_access_audit`，`resource_type=raw`，resource 记录 `mapping_preview:{object}:{anchor}`，reason code 区分 `preview_allowed/unauthorized/token_not_configured`；
- 审计只记主体、source、资源、offset/limit、返回行数和 request ID，不记录 Token、草稿正文、源值、响应、SQL 或 traceback。

### 3.8 零业务副作用

Preview 求值必须使用 `LandingStore.open_readonly()` 和显式读事务。唯一允许的持久化变化是独立写连接产生的一条访问审计；以下状态在成功、空样本、422、并发写入和内部失败路径都不得变化：

```text
raw_* 行与元数据
obj_* / objv_* 表、schema 和内容
d2a_quarantine
d2a_sync_state
d2a_sync_run / d2a_run_step
d2a_dataset_version / d2a_object_version
published 指针与 previous_dataset_version
模板文件
```

Preview 不生成 run/batch/dataset/object version，不占用 M2 的 building 槽位，不触发 GC，不更新隔离状态，也不保存草稿或响应。

### 3.9 HTTP 错误

| HTTP | reason_code | 语义 |
| --- | --- | --- |
| 401 | `unauthorized` | Bearer 错误或缺失 |
| 403 | `token_not_configured` | 控制台未配置可用于 raw 的 Token |
| 404 | `object_not_found` / `source_not_found` / `raw_table_not_found` / `sample_batch_not_found` | 资源或指定批次不存在 |
| 409 | `current_binding_unavailable` / `raw_unavailable` | 当前模式无 binding，或 raw 尚未落地 |
| 422 | `draft_invalid` / `sample_invalid` / `anchor_changed` | 草稿、范围或可比较性不满足契约 |
| 500 | `preview_failed` + `error_id` | 安全内部错误，不回传异常原文 |

成功空样本返回 `200` 和零计数，不伪装成 404；只有指定了不存在的 `batch_id` 才返回 `404 sample_batch_not_found`。

不要把 Preview 逻辑放进 Vue、Jinja 或 API handler 中复制；不要通过临时 SQLite 表、正式 quarantine 或候选表传递中间结果。

## 5. 前端交互

Preview 入口放在现有模板页的已选对象/binding 区域，不新增顶层导航：

1. 选择 source；默认当前 binding；
2. 设置批次（可空）、offset 和 limit；
3. “使用临时草稿”将当前 binding 复制为只存在于浏览器内存的 JSON 文本；没有当前 binding 时从空草稿开始；
4. 本地只做 JSON 语法提示，最终语义以服务端 422 为准；
5. 提交后打开结果抽屉，始终显示“只读预览，不会保存/发布”；
6. 摘要卡展示映射/隔离/熔断预测、样本批次和 fingerprint；
7. 行表展示 current/candidate 状态、字段 diff 和安全问题；
8. 单独展示 enum gaps、业务键问题和 derived 覆盖率；
9. 切换对象/source/草稿后旧结果标记 stale 或清空，迟到响应不得覆盖新选择；
10. 覆盖 idle/loading/empty/success/warning/error/unauthorized，提交期间禁用重复请求。

前端不提供“保存模板”“应用草稿”“发布候选”按钮。用户需要正式修改时仍走受控模板文件变更、代码审查、Preview、完整数据集 apply/publish 流程。

## 7. 测试矩阵

### 7.1 纯转换一致性

- current binding 的 Preview 行结果与同一输入调用正式转换包装完全一致；
- map 未覆盖、enum 非法、int/decimal/money/bool 转换失败逐类命中稳定 reason code；
- derived 多规则首命中、default、无命中、非法枚举和前置转换失败覆盖；
- 业务键单列/复合键缺失、样本内重复覆盖；
- `would_trip_breaker` 在 `== threshold` 为 false、`> threshold` 为 true；
- 现有 `tests/test_mapping_apply.py`、dataset build、publish/retry 全部无回归。

### 7.2 样本与草稿

- offset/limit 边界、最大 200、稳定主键排序；
- 单主键/复合主键、软删排除、指定批次、跨批次和空表；
- 同一只读事务内并发 upsert 不导致 current/candidate 样本漂移；
- fingerprint 对同一快照稳定，对行 hash/批次/主键变化敏感；
- current 模式、等价草稿、修改 map、修改 derived、无 current + 新草稿；
- 锚表变化、越权 raw 表、未知 source/table/列、非法表达式和超大草稿被拒绝；
- draft 不落盘，后续 GET templates 和正式 apply 仍读取原 binding。

### 7.3 聚合与 Diff

- mapped/quarantined/total、比率和熔断预测一致；
- enum gaps 按 field/value 聚合，敏感值只返回遮罩；
- derived 行覆盖率、规则覆盖率、default/unmatched 恒等式；
- 状态从 mapped↔quarantined 和字段值变化均进入 diff；
- 无 current 时 diff unavailable，不拿 published 表伪造 before；
- duplicate 明确为 sample scope，响应带“样本外重复未检查”警示。

### 7.4 安全与副作用

- 未配 Token、无 Bearer、错误 Bearer、正确 Bearer及访问审计；
- 属性输出、issue value、diff before/after 的敏感值均遮罩；草稿不能降级敏感性；
- 未分类 raw 列、SQL、物理表、异常原文、traceback、Token 和草稿正文不出网/不进审计；
- 成功、空样本、422、500、客户端断开和并发 publish 时，受保护表内容、schema 和 published 指针不变；
- Preview 不创建 sync run/step、dataset/object version、quarantine、obj/objv 或临时持久表；
- 多 source 互不读取，draft source 不能跨源。

### 7.5 前端与 E2E

- 当前 binding Preview 正常显示摘要、样本证据和零/非零问题；
- 草稿修复一个枚举 gap 后，diff 和计数同时变化；
- 草稿引入 derived 漏洞后覆盖率和隔离结果可定位；
- 401/403/422/500、空 raw、无 current binding、迟到响应、重复点击；
- 页面明确无保存/发布按钮；Preview 后 datasets、quarantine、runs 页面数据不变；
- Mock 与 Real 契约一致，`/`、`/v0`、`/v1` 既有页面无回归。

## 9. 风险与控制

| 风险 | 控制 |
| --- | --- |
| Preview 与 apply 逐渐分叉 | 先提纯转换核心；一致性测试直接比较同一输入的结构化结果 |
| current/draft 取到不同 raw 行 | 单只读事务冻结锚主键集合；锚表变更 fail-closed |
| 样本被误解为全量证明 | 所有 duplicate/coverage 指标标记 sample scope，并提示样本外未检查 |
| 草稿扩大 raw 访问或注入 SQL | source/table 精确白名单、窄表达式解析、参数绑定、固定排序、响应上限 |
| Preview 泄露敏感原值 | 服务端属性敏感标记、current/draft 敏感并集、unknown 不返回、审计不记正文 |
| “无副作用”被访问审计混淆 | 明确 access audit 是唯一允许写入；业务表/schema/pointer 单独做前后快照断言 |
| 大样本或复杂规则拖慢控制台 | limit≤200、offset/草稿/规则上限；单请求无持久任务，不进入全局轮询 |
| diff 被误认为与已发布版本比较 | 响应和 UI 明示 before=current binding on same raw sample；不读 objv_* 做 diff |

## 10. 明确非目标

- 不保存、审批、版本化或发布临时草稿；
- 不提供在线生产模板编辑器和 apply/publish 快捷按钮；
- 不写正式隔离区、候选对象表、Run、版本元数据或水位；
- 不比较任意历史 dataset/object version；
- 不在 M3 生成 M4 字段级血缘或逐字段源记录持久化；
- 不支持任意 SQL、任意 join、计算表达式或新映射语言；
- 不承诺小样本发现全数据集重复或证明 binding 业务语义正确；
- 不提前实现 v0.4 schema fingerprint、批次 receipt、跨机对账、RBAC 或压测。
