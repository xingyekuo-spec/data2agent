# 接单评审参考脚本(老板测试)

> 目标:让非技术人 30 秒看到 Agent 用工厂数据干活 —— 一句询单描述,
> Agent 自己查历史成交、毛利口径、响应时长,给出一张接单评审建议卡。
> 可用于本地冒烟、验收讲解和 README 首屏 SVG 再生成。

## 前置(一次性)

```bash
python -m data2agent.showroom.seed                # 生成 E10-like 参考库
claude mcp add d2a-factory -- .venv/bin/python -m data2agent.mcp_server
```

## 参考提示词(复制即用)

> 澳洲客户 C002 新询单:矶钓竿 2.4m 规格约 2000 支,客户目标价 28 美元,
> 要求 9 月底前交货。请基于我们的历史数据做接单评审:
> 参考这个客户和同类产品的历史成交价、我们的毛利率水平、这个客户的账期与合作情况,
> 给出"接 / 谨慎接 / 不接"的建议和理由。

## 预期的 Agent 工作过程(核对点)

1. `query_objects` 查 **Quotation**(filters: customer=C002)——
   发现 QT2603-006:同款矶钓竿 2.4m UL,1820 支 @ **31.73 USD 成交**并转为订单 SO2603-003;
2. `query_objects` 查 **Customer** —— C002 账期 90 天(联系方式自动脱敏为 `***`,可作安全卖点特写);
3. `query_metrics` 查 **gross_margin_rate**(group_by: 客户)—— C002 历史毛利约 29.6%,响应中带 draft 口径警示;
4. 结论应指出:目标价 28 USD 比三个月前同款成交价低约 12%,叠加 90 天账期,
   建议"谨慎接 / 还价",并注明口径未经现场校准 —— **诚实声明贯穿到回答里**。

加分镜头:Agent 顺手调 `overdue_receivable_amount` 时,工具会诚实返回
"依赖应收对象,首批未覆盖" —— 边界清晰也是参考链的一部分。

## 记录建议

- 终端窗口放大字号,提问 → 工具调用滚动 → 建议卡,全程 ≤ 60 秒;
- 首屏截图选"建议卡"那一帧(结论 + 三条理由 + 口径警示),而不是工具调用过程;
- 数据由固定随机种子生成(seed=42, asof=2026-07-10),换机器复现相同数字。
